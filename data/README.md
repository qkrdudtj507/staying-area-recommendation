# 데이터 안내

`데이터_출처.xlsx`에 세 개의 시트가 있습니다.

- **total2**: 자치구별 원본 통합 데이터 (인구, 범죄, 인프라, 환경 등 39개 변수)
- **Sheet1**: 각 변수의 출처 기관·데이터셋명·링크 목록 (서울시 열린데이터광장, 공공데이터포털, 통계데이터센터 등)
- **비율 조정 데이터**: 면적·인구 대비 비율로 정규화한 버전 (일부 `#REF!` 오류 셀 포함 — 원본 엑셀 수식 참조가 깨진 것으로 보이며, 재계산이 필요합니다)

## 분석 코드가 필요로 하는 입력 파일

- `analysis/01_초기시도_...R` → `data_house_combine.csv`, `public.csv`, `traffic.csv` (초기 시도, `total2` 시트를 부문별로 나눈 버전으로 추정)
- `analysis/02_최종_...R` → `data_pca_minmax.csv` ("비율 조정 데이터" 시트를 min-max 스케일링한 버전으로 추정)

원본 CSV 파일 자체는 이 저장소에 없으니, 위 엑셀 시트를 바탕으로 직접 준비해주세요.
